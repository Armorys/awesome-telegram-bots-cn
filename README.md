## 📌 项目说明

**Awesome Telegram Bots（中文精选）** 是一个面向中文用户的 Telegram 机器人精选列表。

本项目遵循 Awesome List 规范，专注于 **高质量、实用性强、可公开访问** 的 Telegram 机器人，而不是简单罗列所有机器人。

## 如何把机器人加到群组

1. 打开群组，点击群名进入群信息页
2. 点击「添加成员」，搜索机器人用户名并添加（搜不到时，先在 Telegram 全局搜索该机器人并点一次 Start）
3. 按机器人说明设为管理员或授予权限（验证类机器人通常需要「删除消息」「封禁用户」权限）
4. 部分机器人需要在群内发送命令完成配置，按其帮助说明操作即可

## 常见问题（FAQ）

**Q：Telegram 机器人怎么找？**
A：先按用途在本列表的分类里找；找群组、频道、视频等资源，用「电报资源搜索」分类里的极搜（@jiso）、SOSO（@soso）、超级索引（@CJSY）。

**Q：群管理机器人推荐哪个？**
A：要功能全面选 Combot（@combot）或 Rose（@MissRose_bot）；只需要入群验证码选 Shieldy（@shieldy_bot）或入群验证机器人（@P4CaptchaBot）；广告多再加 Protectron（@ProtectronBot）拦截链接广告。

**Q：有免费的 AI 机器人吗？**
