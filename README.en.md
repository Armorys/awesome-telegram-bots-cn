## How to Add a Bot to a Group

1. Open the group, tap the group name to open its info page
2. Tap "Add Members", search the bot's username and add it (if it does not appear, search the bot globally in Telegram and tap Start once first)
3. Grant admin rights or permissions as the bot instructs (captcha bots usually need "Delete messages" and "Ban users")
4. Some bots need a command in the group to finish setup; follow their help text

## FAQ

**Q: How do I find Telegram bots?**
A: Start with the categories in this list. To find groups, channels and videos, use the search bots in "Resource Search & Videos", such as Jisou (@jiso), SOSO (@soso) and Super Index (@CJSY).

**Q: Which group management bot should I pick?**
A: For full features choose Combot (@combot) or Rose (@MissRose_bot). For join captcha only, Shieldy (@shieldy_bot) or @P4CaptchaBot. If link ads are a problem, add Protectron (@ProtectronBot).

**Q: Are there free AI bots?**
A: Yes. Every bot in the "AI Bots" section was verified as active, e.g. @GPT4Telegrambot (~5.08M monthly users). Note: AI bots churn fast, and there is no official OpenAI Telegram bot, so be careful with official-sounding names and try small amounts before paying.

**Q: Which bot downloads YouTube / Bilibili videos?**
A: Use @freedlvideo_bot for multi-platform parsing, @utubest_Bot or @YtbDownBot for YouTube, and @bilibiliparse_bot for Bilibili. Do not download infringing content.

**Q: Are Telegram bots safe?**
A: Grant only the permissions a bot needs. Never enter passwords, verification codes or payment details in a bot chat. Be extra careful with bots asking for top-ups or paid API access. Report abusive bots to @SpamBot.

**Q: How often is this list updated?**
A: Continuously. Monthly user figures come from public community data (last verified 2026-10-31) and are for reference only. Please open an Issue for dead entries.
